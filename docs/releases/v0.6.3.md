## Highlights

- **Firefox back in the COSMIC dock.** The dock pinned the browser by a name Fedora 44 no longer uses.
- **AgentUX's dock in the COSMIC live session**, with **Install AgentUX** first instead of Fedora's installer.
- **No new ISO needed.** Installed systems get this release with `sudo bootc upgrade` (or from the software center), then a reboot.
