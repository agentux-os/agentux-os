## Highlights

- **The AgentUX accent on COSMIC.** Buttons, focus rings and selection now use AgentUX Lime (a darker green in the light theme) from the first login, without opening COSMIC Settings.
- **Firefox back in the COSMIC dock.** The dock pinned the browser by a name Fedora 44 no longer uses.
- **AgentUX's dock in the COSMIC live session**, with **Install AgentUX** first instead of Fedora's installer.
- **No new ISO needed.** Installed systems get this release with `sudo bootc upgrade` (or from the software center), then a reboot. Users who already picked an accent in COSMIC Settings keep theirs.
