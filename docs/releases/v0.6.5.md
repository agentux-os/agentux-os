## Highlights

- **Runs use the agents you set up.** Without an `agentux.yaml`, runs plan, implement and review with the agent CLIs you are signed in to, not always Claude Code and Codex. **New run** in the cockpit can pick the agent for each role.
- **Clone a repository from New run.** GitHub's `owner/repo`, or the https or SSH URL of any Git host, cloned into `~/src`.
- **Usage limits no longer stop a run.** When an agent hits its 5-hour or weekly limit, a quota or its credits, AgentUX reads when the limit resets and keeps that agent (or model) out of use until then. The step goes to a role's `fallback` or another signed-in agent, or the run waits and goes on by itself at the reset. **Limit lifted** and **Retry now** bring an agent back early after you add credits or reset a limit.
- **Agents that stop responding are given up on.** A turn with no activity for 10 minutes (60 while a command runs) is cancelled, and the step goes to another agent or waits.
- **Welcome to AgentUX** sees the Antigravity CLI's sign-in, and on COSMIC it waits for COSMIC's own first-login setup instead of opening on top of it.
- **No new ISO needed.** Installed systems get this release with `sudo bootc upgrade` (or from the software center), then a reboot.
