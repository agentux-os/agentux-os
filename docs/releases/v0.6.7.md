## Highlights

- **Signed AgentUX packages.** The agentux, agentux-cockpit and agentux-office RPMs are now signed with the AgentUX RPM key (fingerprint `7217 759E 0D14 1913 9B7C  148C 3116 C5F0 DECE 4517`). The image build refuses any AgentUX RPM without a valid signature, and installed systems carry the key in `/etc/pki/rpm-gpg/RPM-GPG-KEY-agentux`.
- **AgentUX 0.5.1, the cockpit 0.5.13, AgentUX Office 0.1.0**: the same software as v0.6.6, now signed.
- **No new ISO needed.** Installed systems get this release with `sudo bootc upgrade` (or from the software center), then a reboot.
