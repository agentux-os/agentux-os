## Highlights

- **AgentUX's accent color on COSMIC.** Buttons, focus rings and window borders use the AgentUX lime out of the box. Before, it only appeared after a change in COSMIC Settings, because COSMIC 1.10 reads a newer theme format.
- **No new ISO needed.** Installed systems get this release with `sudo bootc upgrade` (or from the software center), then a reboot.
