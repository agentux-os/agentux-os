## Highlights

- **Runs use the agents you set up.** Without an `agentux.yaml`, runs plan, implement and review with the agent CLIs you are signed in to, in your order, not always Claude Code and Codex. **New run** can pick the agent and the model for each role.
- **Clone a repository from New run.** GitHub's `owner/repo`, or the https or SSH URL of any Git host, cloned into `~/src` (or the folder set in Settings).
- **Usage limits no longer stop a run.** When an agent hits its 5-hour or weekly limit, a quota or its credits, AgentUX reads when the limit resets and keeps that agent (or model) out of use until then. The step goes to a role's `fallback` or another signed-in agent, or the run waits and goes on by itself at the reset. **Limit lifted** and **Retry now** bring an agent back early after you add credits or reset a limit. Codex's own session logs show its plan windows, so a spent window is skipped before it is hit.
- **Agents that stop responding are given up on.** A turn with no activity for 10 minutes (60 while a command runs) is cancelled, and the step goes to another agent or waits.
- **Agents view** (`G` in the cockpit): every agent CLI with its sign-in, version, spending today and this week, plan usage and limits, and **Test**, **Sign in** and **Update**. `aux agents`, `aux limits` and `aux test` do the same from a terminal.
- **Settings** (`,`): agent preferences (order, agent and model per role, what happens at a limit, when a stopped agent is given up on), **API keys** kept in the desktop's secret service and handed to the agents that read them, the clone folder, theme and the penguin helper.
- **Desktop notifications** when an agent hits a limit or stops responding, another takes over, or a run waits or goes on.
- **Welcome to AgentUX** sees the Antigravity CLI's sign-in, and on COSMIC it waits for COSMIC's own first-login setup instead of opening on top of it.
- **No new ISO needed.** Installed systems get this release with `sudo bootc upgrade` (or from the software center), then a reboot.
