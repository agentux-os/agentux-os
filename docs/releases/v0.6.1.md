## Highlights

- **A more responsive daemon.** `agentuxd` no longer stalls while the database writes to disk, so the cockpit and the agents keep getting answers during a busy run.
- **No more lost runs to a duplicate id.** A new run, session, project or approval whose short id was already taken failed to save; it now gets another id.
- **No new ISO needed.** Installed systems get this release with `sudo bootc upgrade` (or from the software center), then a reboot.
