## Highlights

- **COSMIC joins Plasma as a released desktop.** Each release now ships both, each as a live ISO to try it and an offline installer ISO, for x86_64 and aarch64; COSMIC systems follow `ghcr.io/agentux-os/agentux-cosmic:stable`.
- **ISO names that say what they are:** `agentux-<desktop>-<live|installer>-<version>-<arch>.iso`, e.g. `agentux-plasma-live-v0.6.0-x86_64.iso` or `agentux-cosmic-installer-v0.6.0-aarch64.iso`; `iso/stable/` has the same names without the version.
- **Hyprland is retired** ([ADR 0018](https://github.com/agentux-os/agentux/blob/main/docs/adr/0018-retire-the-hyprland-variant.md)). A Hyprland system moves to Plasma, home and settings kept, with `sudo bootc switch ghcr.io/agentux-os/agentux:stable`.
