## Highlights

- **COSMIC looks like AgentUX.** The AgentUX wallpaper (dark and light), the lime accent colour, and a dock that starts with the cockpit, the terminal and Firefox.
- **Super+C opens the cockpit, on both desktops.** COSMIC and Plasma now use the same shortcut; Super+Return opens a terminal on COSMIC.
- **No new ISO needed.** Installed systems get this release with `sudo bootc upgrade` (or from the software center), then a reboot. Changes to the desktop defaults apply to users who have not changed those settings themselves.
